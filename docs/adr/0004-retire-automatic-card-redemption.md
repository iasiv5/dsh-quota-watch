# Retire automatic card redemption; keep explicit manual use

> Status: Accepted and implemented in the source tree (2026-10-12); not yet shipped or installed on any running profile. Supersedes only the automatic-use decision in ADR 0003 once shipped. Until the new build is actually installed and the host restarted, a running OLD host may still hold an automatic authorization in memory — the retirement's saved all-off override takes effect on the new host's first start.

Quota Watch prioritizes observing provider-reported quotas and available GLM reset cards. We will remove standing host-side authorization and scheduled automatic card redemption, while retaining read-only card listing and explicitly confirmed manual redemption. This gives up automatic continuity during long runs in exchange for predictable, user-initiated consumption of an irreversible entitlement and a smaller interface. On first start, the replacement must durably set both legacy enabled flags to false, creating a disabled saved override even when none existed so an older release cannot revive a profile-level authorization after rollback. A write failure leaves the new host incapable of automatic spending but must surface the rollback risk; deleting only the browser controls or simply deleting the old settings file would not satisfy this decision.
